# Security policy

The current `0.1.x` line receives security fixes.

Report vulnerabilities through GitHub private vulnerability reporting for this repository. If that channel is unavailable, ask the maintainer for a private contact without including vulnerability details in a public issue.

Useful reports identify the affected command or exported function, the trust boundary crossed, reproduction steps with sanitized paths and credentials, impact, and any proposed mitigation. Relevant boundaries include repository provenance, path ownership and symlinks, skill discovery roots, binding state, compatibility caches, and atomic state locks.
